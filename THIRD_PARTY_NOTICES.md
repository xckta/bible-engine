# Third-party corpus notices

The application source code does not bundle full copyrighted Bible translations.

The included offline demo excerpts are from public-domain texts:

- **World English Bible Classic (WEB)** — eBible.org identifies the translation as public domain. Source/setup reference: https://ebible.org/find/details.php?all=1&id=eng-web
- **American Standard Version (ASV, 1901)** — eBible.org identifies the translation as public domain. Source/setup reference: https://ebible.org/find/details.php?all=1&id=eng-asv

`scripts/fetch_public_domain.py` downloads the full USFM archives from eBible.org when run by the user. Do not add another translation to the repository unless its storage, redistribution, and intended use are permitted by its license.
